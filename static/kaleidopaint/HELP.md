# Kaleidopaint Help

Kaleidopaint helps you paint mirrored designs quickly. Every stroke can be repeated by symmetry rules.

## If You Want To...

### Paint mirrored art

1. Open the **Draw** tab.
2. Select **Paint**.
3. Drag on the canvas.
4. Open **Symmetry** and choose your mode.

### Erase parts of a drawing

1. Keep the **Paint** tool selected.
2. Use **right mouse drag** to erase.
3. The erase stroke also follows symmetry.

### Pick a color from the canvas

1. In **Draw**, select **Eyedropper**.
2. Click a pixel on the canvas.
3. Switch back to **Paint** and continue drawing.

### Re-center symmetry

1. Select **Origin** in **Draw**.
2. Click where you want the symmetry center.
3. Return to **Paint** to draw around that center.

### Rotate the symmetry axes

1. Select **Rotate** in **Draw**.
2. Drag to set the angle.
3. Switch back to **Paint**.

### Save and export your work

- **File -> Export PNG** saves your image.
- Kaleidopaint auto-saves your latest canvas in your browser.
- **File -> New canvas** starts fresh at a chosen size.

## Tabs

### Color Tab

- Choose a color with the picker.
- Use palette swatches for quick reuse.
- Use hex input for exact values (for example `#ff8800`).

### Draw Tab

- **Tool**
  - **Paint**: draw
  - **Fill**: flood fill a region
  - **Origin**: set symmetry center
  - **Rotate**: rotate symmetry angle
  - **Eyedropper**: sample color
  - **Image**: stamp a loaded image as a brush
- **Brush size**: stroke diameter in pixels.
- **Brush shape**: round or square-like forms (depends on options).
- **Opacity / Flow / Softness**: controls how hard or soft paint is applied.
- **Scatter / Spacing**: controls stroke texture and spacing between paint stamps.

### Symmetry Tab

- **Enable symmetry**: toggles mirrored painting on/off.
- **Mode**:
  - **Polar**: radial mirror around a center.
  - **Mosaic**: tiled geometric repetitions.
- **Folds** (polar): number of radial copies.
- **Origin X / Y**: exact symmetry center position.
- **Rotation**: rotates symmetry sectors.
- **Preview**: show/hide symmetry guide overlay.

## Keyboard and Mouse Shortcuts

- **Cmd/Ctrl + Z**: undo
- **Cmd/Ctrl + Shift + Z**: redo
- **Mouse wheel**: zoom
- **Space + drag**: pan
- **Middle mouse drag**: pan
- **Left drag**: paint
- **Right drag**: erase

---

## Beginner Tips

- Start with **Polar** mode and 6 folds.
- Use a large brush for base forms, then smaller brushes for detail.
- Move the origin often to create layered mandala effects.
- If lines look too harsh, lower flow and increase softness.
- Export versions as PNG as you iterate.
